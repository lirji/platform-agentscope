## 技术决策与影响

技术未知、候选、选型、架构和影响见 [PLAN](PLAN.md)。三个设计 Gate 在产品编码前确认；模型适配器的终帧/usage 行为通过锁定 AgentScope 2.0.5 本地源码和真实适配器测试核对，没有对外部版本或性能作推测。

- 选择模型共同适配边界，避免 Runner-only 观测漏掉规划/评审，避免从 worker 结果复用历史 token 重复计费。
- 以请求显式上下文创建协程局部会话，节点/角色各自作用域；并行请求不共享统计。同身份的规划与执行合并一个片段，跨身份嵌套不能复用会话。
- 使用有界后台事件投递，不把诊断网络延迟插入依赖调度。普通投递故障记录缺口并保持业务结果；结束时有界排空并回收发布协程。
- 异步管理器绑定centralTaskId/leaseEpoch和外层deadline；v1重新领取也标记历史缺口。新增观测开关排除在执行配置摘要之外，避免升级前排队任务失配。
- 持久检查点格式不变；恢复后历史不完整，总成本为未知。新增属性 resumed 只用于当前进程观测，不是持久任务状态。
- 费用是 Decimal 估算；显式价格配置区分免费与未配置，未知 usage 不能当零。预算保守预留不进入实际费用计算。

## 企业级边界与自审

- 并发/水平扩展：统计以 executionId 隔离，指标不含高基数标识；跨副本全局计费与公平调度不在本功能。
- 幂等/重放：中央 eventKey 沿用原worker/epoch/序号规则；消费方按callId去重。跨接管真实重做属于新模型调用。
- 事务/数据：中央事件写入沿用原租约校验；无事务迁移。诊断不是审计或账单权威，缺口明确计数。
- 故障恢复：SIGKILL可能丢失未投递日志/事件；恢复片段不将旧历史补零。此次恢复归因用应用会话重建测试验证；没有新增生产灾备承诺。
- 安全：不采集提示词、模型输出、工具数据、凭据和原始异常；原任务权限/SSE脱敏保持。新增封闭原因码限制指标标签基数。
- 本人独立复查发现并修正：中央事件允许列表遗漏、诊断投递进入调度耗时、恢复外层截止时间、未消费流误报零、重规划后最终摘要状态、未知价格与合法免费区分。
- 未执行独立代理评审；不把本地通过当作远程CI通过。Java基线a23cc6c远程38575411792在既有依赖SBOM扫描失败，此依赖安全问题不纳入本次范围。
